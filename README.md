# Another World

Готический 2D-платформер на Godot 4. Кира, душа в цепях, вспоминает своё имя, разбивает цепи и ищет своё тело, чтобы ожить.

Сюжет, три уровня, цепи и прокачка описаны в [docs/GDD.md](docs/GDD.md).

## Как запустить (первый раз)

1. **Скачай Godot.** Зайди на https://godotengine.org/download и скачай **Godot 4.5** (обычную версию, не .NET). Установка не нужна: это один файл. Распакуй архив и запусти `Godot_v4.5...exe` (на Mac перетащи Godot в «Программы»).
2. **Скачай проект.** На странице репозитория на GitHub нажми зелёную кнопку **Code → Download ZIP** и распакуй архив. (Или `git clone`, если пользуешься git.)
3. **Открой проект в Godot.** В окне менеджера проектов нажми **Import** (Импорт), выбери файл `project.godot` в папке проекта и нажми **Import & Edit**. При первом открытии Godot пару минут обрабатывает картинки, это нормально.
4. **Запусти игру.** Нажми **F5** или треугольник ▶ в правом верхнем углу. Откроется главное меню.

Управление на ПК: A/D ходьба, Пробел прыжок, J хлыст, K бросок цепи, L (или Shift) крюк, E действие, Esc пауза.
Клавиша **F2** включает экранные кнопки, как на планшете, чтобы проверить их мышкой.

## Что где лежит

```
data/               все тексты и числа игры (можно менять без программирования)
  player.json         скорость, прыжок, здоровье Киры, сила цепей
  upgrades.json       улучшения и их цены
  items.json          цепи и буквы имени (что дают и что забирают)
  notes.json          записки
  levels/             карты уровней
scenes/             сцены Godot (Кира, враги, предметы, меню)
scripts/            код на GDScript
assets/textures/    картинки (сейчас временные, нарисованные скриптом)
docs/GDD.md         дизайн-документ
tools/              вспомогательные скрипты на Python
tests/              автопроверка
```

## Как менять игру без программирования

**Тексты записок, цепей и букв:** `data/notes.json`, `data/items.json`. У предмета поле `grants` перечисляет приёмы, которые он даёт, а `removes` приёмы, которые забирает (`whip` хлыст, `throw` бросок, `hook` крюк, `free` цепей нет, `wall_jump` прыжки от стен).

**Сложность и прокачка:** `data/player.json` (например, `jump_velocity` это сила прыжка, `hook_range` дальность крюка) и `data/upgrades.json` (цены в `costs`).

**Уровни:** `data/levels/level_01.json` (склеп), `level_02.json` (катакомбы), `level_03.json` (глубины). Поле `map` это картинка из символов, каждый символ означает клетку 32×32 пикселя:

| Символ | Что это |
|---|---|
| `#` | стена или пол |
| `=` | полка, на неё можно запрыгнуть снизу |
| `P` | старт Киры |
| `o` | осколок памяти |
| `^` | шипы |
| `S` | голубое пламя (прокачка и сохранение) |
| `e` | душа |
| `k` | скелет в броне |
| `d` | заводная кукла |
| `H` | железное кольцо для крюка |
| `c` | голубой факел |
| `C` | погоня: стена тьмы |
| другие буквы и цифры | описаны в `entities` этого же файла: записки, цепи, буквы имени, выходы, мысли Киры, цветные огни |

Все строки карты должны быть одной длины. Прыжок поднимает Киру на 2 клетки, перепрыгнуть она может пропасть в 3–4 клетки, а на крюке перелетает 8.
Стартовые карты удобно перерисовывать скриптом `tools/build_levels.py`.

**Картинки:** замени PNG в `assets/textures/`, оставив то же имя файла. Новые спрайты лучше рисовать в тех же размерах (Кира 24×44, тайлы 32×32).

## Сборка для Android

1. В Godot: **Editor → Manage Export Templates → Download and Install**.
2. Установи Android Studio (оттуда нужен Android SDK) и Java 17, затем укажи пути в **Editor → Editor Settings → Export → Android**.
3. **Project → Export → Add… → Android**, затем **Export Project**. Получится `.apk`, его можно поставить на планшет.

Подробная официальная инструкция: https://docs.godotengine.org/ru/4.x/tutorials/export/exporting_for_android.html

## Автопроверка

```
godot --headless --path . res://tests/smoke_test.tscn
```

Проверяет, что все три уровня собираются, Кира бегает и прыгает, хлыст и бросок работают, крюк переносит через пропасть, прыжки от стен вытаскивают из шахты, буквы правильно забирают цепи, а прокачка считается верно. В конце пишет `SMOKE OK`.
