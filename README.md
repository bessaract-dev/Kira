# Another World

Готический 2D-платформер на Godot 4. Девочка-душа ищет своё тело, чтобы вернуться к жизни.

Подробности о сюжете, уровнях и прокачке: [docs/GDD.md](docs/GDD.md).

## Как запустить (первый раз)

1. **Скачай Godot.** Зайди на https://godotengine.org/download и скачай **Godot 4.5** (обычную версию, не .NET). Установка не нужна: это один файл. Распакуй архив и запусти `Godot_v4.5...exe` (на Mac перетащи Godot в «Программы»).
2. **Скачай проект.** На странице репозитория на GitHub нажми зелёную кнопку **Code → Download ZIP** и распакуй архив. (Или `git clone`, если пользуешься git.)
3. **Открой проект в Godot.** В окне менеджера проектов нажми **Import** (Импорт), выбери файл `project.godot` в папке проекта и нажми **Import & Edit**. При первом открытии Godot пару минут обрабатывает картинки, это нормально.
4. **Запусти игру.** Нажми **F5** или треугольник ▶ в правом верхнем углу. Откроется главное меню.

Управление на ПК: A/D ходьба, Пробел прыжок, J вспышка, E действие, Shift рывок (после прокачки), Esc пауза.
Клавиша **F2** включает экранные кнопки, как на планшете, чтобы проверить их мышкой.

## Что где лежит

```
data/               все тексты и числа игры (можно менять без программирования)
  player.json         скорость, прыжок, здоровье героини
  upgrades.json       улучшения и их цены
  items.json          предметы
  notes.json          записки
  levels/             карты уровней
scenes/             сцены Godot (героиня, враги, предметы, меню)
scripts/            код на GDScript
assets/textures/    картинки (сейчас временные, нарисованные скриптом)
docs/GDD.md         дизайн-документ
tools/              вспомогательные скрипты на Python
tests/              автопроверка
```

## Как менять игру без программирования

**Тексты записок и предметов:** `data/notes.json`, `data/items.json`.

**Сложность и прокачка:** `data/player.json` (например, `jump_velocity` это сила прыжка) и `data/upgrades.json` (цены в `costs`).

**Уровни:** `data/levels/level_01.json`. Поле `map` это картинка из символов, каждый символ означает клетку 32×32 пикселя:

| Символ | Что это |
|---|---|
| `#` | стена или пол |
| `=` | полка, на неё можно запрыгнуть снизу |
| `P` | старт героини |
| `o` | осколок памяти |
| `^` | шипы |
| `S` | свеча-святилище (прокачка и сохранение) |
| `E` | враг-тень |
| `c` | свеча (просто свет) |
| другие буквы | описаны в `entities` этого же файла: записки, предметы, двери, надписи |

Все строки карты должны быть одной длины. Одиночный прыжок поднимает героиню на 2 клетки, двойной примерно на 4.

**Картинки:** замени PNG в `assets/textures/`, оставив то же имя файла. Новые спрайты лучше рисовать в тех же размерах (героиня 24×44, тайлы 32×32).

## Сборка для Android

1. В Godot: **Editor → Manage Export Templates → Download and Install**.
2. Установи Android Studio (оттуда нужен Android SDK) и Java 17, затем укажи пути в **Editor → Editor Settings → Export → Android**.
3. **Project → Export → Add… → Android**, затем **Export Project**. Получится `.apk`, его можно поставить на планшет.

Подробная официальная инструкция: https://docs.godotengine.org/ru/4.x/tutorials/export/exporting_for_android.html

## Автопроверка

```
godot --headless --path . res://tests/smoke_test.tscn
```

Проверяет, что оба уровня собираются, героиня стоит на полу, бегает и прыгает, а прокачка считается правильно. В конце пишет `SMOKE OK`.
